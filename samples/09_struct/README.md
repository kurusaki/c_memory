# 構造体はなぜ必要？

例えば、一人分の情報を管理したいとします。

* 名前
* 年齢
* 身長

この3つの情報が必要です。

構造体を使わない場合は、

```c
char name[32];
int age;
double height;
```

のように、それぞれ別々の変数になります。

もちろんこれでも動きますが、

これらが

**「一人分の情報」**

であることが分かりにくくなります。

関連するデータは、一つにまとめて扱えた方が便利です。

そこで使うのが構造体です。

---

# 構造体とは？

構造体は、

**関連するデータを一つにまとめた新しい型**

です。

例えば、

```c
struct Person {
    char name[32];
    int age;
    double height;
};
```

このように書くと、

名前・年齢・身長をまとめた

**Person型**

を定義できます。

ここで重要なのは、

まだ変数は作られていないということです。

これは、

設計図を作った状態になります。

---

# 構造体変数を作る

それでは、

この設計図を使って変数を作ってみます。

```c
struct Person person;
```

これで

**person**

という変数が作られました。

char や int と同じように、

struct Person も

一つの型として扱えるようになります。

---

# サンプルプログラム

今回使用するプログラムはこちらです。

```c
/*
 * struct_basic.c
 *
 * 第9回 構造体とは何か？
 * ～関連するデータを一つにまとめよう～
 */

#include <stdio.h>

struct Person {
    char name[32];
    int age;
    double height;
};

int main(void)
{
    struct Person person;

    snprintf(person.name, sizeof(person.name), "Taro");
    person.age = 20;
    person.height = 170.5;

    printf("名前 : %s\n", person.name);
    printf("年齢 : %d\n", person.age);
    printf("身長 : %.1f cm\n", person.height);

    return 0;
}
```

今回は、このプログラムを使って構造体の基本を確認していきます。

## 構造体を定義している部分

まずはこちらです。

```c
struct Person {
    char name[32];
    int age;
    double height;
};
```

ここでは、

名前、年齢、身長という

関連するデータを一つにまとめています。

この時点では、

まだ変数は作られていません。

**Personという新しい型を定義している**

だけです。

---

## 構造体変数を作る

次はこちらです。

```c
struct Person person;
```

これは、

Person型の変数

**person**

を作っています。

今まで、

```c
int number;
char ch;
```

のように変数を作ってきましたが、

それと同じです。

型が

int や char ではなく、

struct Person

になっただけです。

---

## メンバーへ値を代入する

続いて、

構造体の中へ値を設定しています。

```c
snprintf(person.name, sizeof(person.name), "Taro");

person.age = 20;

person.height = 170.5;
```

構造体の中のデータは、

**ドット演算子（.）**

を使ってアクセスします。

ドットの左側が構造体変数、

右側がメンバー名です。

---

## メンバーを表示する

表示するときも同じです。

```c
printf("名前 : %s\n", person.name);
printf("年齢 : %d\n", person.age);
printf("身長 : %.1f cm\n", person.height);
```

普通の変数と同じように、

printfで表示できます。

---

# 構造体も「型」の一つ

ここで覚えてほしいのは、

構造体は特別な存在ではないということです。

これまで使ってきた

* char
* int
* double

と同じように、

**struct Person** も

一つの型です。

そして、

その型から

person

という変数を作っています。

つまり、

構造体とは

**複数のデータをまとめた新しい型**

なのです。
